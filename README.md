# fin-dash

Личная статистика расходов и доходов по данным Дзен-мани.

Страница: https://art19323.github.io/fin-dash/

- переключение по месяцам и произвольный период (средние значения за выбранный диапазон месяцев);
- статистика по неделям (пн–вс);
- категории трат и источники доходов, баланс, норма сбережений, средний чек;
- аренда («Мой дом») показана отдельной строкой, чтобы не перекашивать суммы.

Считаются только операции в BYN; переводы между счетами и обмен валюты не входят ни в траты, ни в доходы.
Данные лежат прямо в `index.html` — страница статичная, без бэкенда.
